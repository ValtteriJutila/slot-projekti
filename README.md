Jos saat tietyn symbolikombon voitat rahaa, jos et saa oikeaa komboa et voita mitään.
Käynnistäminen:
1. Varmista että Python on asennettuna
2. Lataa tiedosto python koodi työ.py
3. Aja komennolla: python python koodi työ.py
Käyttö:
Syötät summan minkä haluat pelata ohjelmaan, valitset paljonko laitat panosta ja pyöräytät konetta.
